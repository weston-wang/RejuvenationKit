# RejuvenationKit

RejuvenationKit provides typed, composable tools for quality control, analysis-readiness
profiling, DSP change detection, randomized longitudinal inference, and reproducible study
audits.

Phases 1 and 2 are implemented and available as an alpha. The
[one-command audit](study-audit.md) has been validated end to end on
[public longitudinal canine data](dap-audit-case-study.md). Phase 2 adds
[uncertainty-aware multimodal fusion](multimodal-fusion.md). State-estimation and
combination-analysis phases retain typed interfaces and explicit TODOs.
